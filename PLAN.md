# Reposoup analysis helpers

Reposoup analysis helpers are set of Python3 scripts without any dependencies
that analyses a `compile_commands.json` and generate some text files
that helps project analysis.

## CLI standards

Filenames specified in this specification is reference-only.
File input and output should be done with stdin/stdout,
except C preprocess files(`.i`) that will be generated by the
external process.

For JSON and JSONL I/O, no need to handle malformed input gracefully.

Entire analysis workflow should be look like:

```sh
cd /path/to/project
python3 analyze.py < ./compile_commands.json > rs_project_cmds.jsonl
python3 inject_preprocess.py -b check < rs_project_cmds.jsonl > rs_project_preprocess.jsonl
python3 exec_project.py < rs_project_preprocess.jsonl # Generates *.i
python3 analyze_project.py < rs_project_preprocess.jsonl > result.json
```

## `analyze.py` -- `compile_commands.json` analyzer

`analyze.py` will analyze `compile_commands.json`
and emits `rs_project_cmds.jsonl`.
See `SPEC_ANALYZE.md` for its detailed specs.

### `rs_project_cmds.jsonl`

Format of `rs_project_cmds.jsonl` is a JSONL(JSON with Lines) file.
Each JSON object should have following fields:

- `file` : path of source code
- `directory` : path of directory that the compiler should run on
- `arguments` : Array of string that contains command line arguments

## `inject_preprocess.py` -- Replace command arguments for analysis

`inspect.py` will analyze generated `rs_project_cmds.jsonl` and
emits `rs_project_preprocess.jsonl` that contains replaced command
line that emits preprocessed results.
See `SPEC_INJECT.md` for its detailed specs.

### `rs_project_preprocess.jsonl`

Format of `rs_project_preprocess.jsonl` is almost same as
`rs_project_cmds.jsonl` above but with following additional fields
for each root JSON objects included in the JSONL file.

- `preprocess_file` : Path to preprocessed file(`.i`)

## `exec_project.py` -- Run preprocess commands

`exec_project.py` will run commands that included in
`rs_project_preprocess.jsonl` to emit preprocessed files.

## `analyze_include_tree.py` -- Analyze preprocessed files for include tree

`analyze_project.py` will read `rs_project_preprocess.jsonl` file
and parses all of preprocessed file to construct `rs_project_include_tree.json`
file.
See `INCLUDE_TREE_GENERATION.md` for actual algorithm to generate
the JSON file.
